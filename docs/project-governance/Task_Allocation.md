## Accountability Rules

1. Each Jira task must have one accountable owner.
2. Completed tasks must include appropriate supporting evidence.
3. Code changes must be committed to the appropriate GitHub branch.
4. Important changes must be reviewed before integration into the main branch.
5. Significant changes must be recorded in `Change_Log.md`.
6. Reported technical results must match the final notebook and datasets.
7. Team members must review their assigned work before final submission.
