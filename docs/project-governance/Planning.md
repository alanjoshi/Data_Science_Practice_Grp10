## Dependencies and checkpoints

- Dataset selection and technical design precede pipeline implementation and data cleaning.
- Model evaluation depends on completion of data processing and model development.
- Dashboard outputs depend on reviewed model results.
- Final report integration depends on each member completing their contribution material and technical review.
- Jira statuses, GitHub evidence and report links are checked before final submission.

## Completion criteria

- A task is complete when its deliverable is produced, reviewed and supported by Jira or GitHub evidence.
- Technical outputs must run successfully and show relevant results.
- Model comparisons must report the agreed evaluation metrics.
- Governance records must identify the task, assignee and current status.
- The final report must be internally consistent and all submitted links must work.
